# shared/ — Shared Library Constraints

`shared/ui/` is the **only** source of truth for code shared by pH and Pockets.

- Never edit `addons/*/*/Shared/UI/` — those are generated by `scripts/sync-shared.sh`
  (committed so each addon dir stays loadable, verified byte-for-byte by CI and `sync-shared.sh --check`).
- Every file starts with `local addonName, addon = ...` and hangs off `addon.UI.*`. Never write a global
  (no `_G.PHUI`). `shared/.luacheckrc` makes global writes a lint error.
- No references to addon-specific names (`Pockets`, `pH_*`, adapters, services, addon layout constants).
  `scripts/check-shared.sh` greps for them. Client differences go through hooks such as
  `PHUI.SetForeverDetector`.
- Preserve public APIs and token values; `tests/golden/phui_tokens.lua` snapshots the originals.
- Load order: `PHUI.lua` first, then the rest. Add new files to each consuming addon's TOC.
- Adding a file: drop it in `shared/ui/`, run `scripts/sync-shared.sh`, list it in the TOC(s), commit the staged copies.

Workflow: `scripts/sync-shared.sh` · `scripts/lint.sh` · `scripts/test.sh` · `scripts/build.sh`
(all but sync run sync first; a change here must pass both addons).
